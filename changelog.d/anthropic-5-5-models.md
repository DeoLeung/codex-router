- **Claude Opus 5.5, Fable 5.1, Sonnet 5.5, and Haiku 5.5 are now routable through the Anthropic API provider.** Each ships with Anthropic's documented 1M-token window, text and image input, and the full `low` to `max` effort ladder (defaults: `medium` on Opus 5.5 and Haiku 5.5, `high` on Fable 5.1 and Sonnet 5.5). Opus 4.8 stays available but now sorts below the 5.x line in the picker. The routes use a separately billed Anthropic API key; none of them have been probed live yet.
