- **Upstream Responses WebSocket transport.** Generic providers can declare `transport: "websocket"` (requires the `openai-responses` adapter) and their turns ride pooled persistent `responses_websockets=2026-02-06` connections instead of one HTTPS POST per turn: the api-forwarder terminates the protocol with the provider's own credential under the same origin/DNS confinement as HTTP, LiteLLM is bypassed like DeepSeek Responses, and a refused upgrade, full pool, or in-effect proxy falls back to the HTTP path (with a per-provider circuit breaker). Native models get the same transport opt-in via `MODEL_ROUTER_NATIVE_TRANSPORT`/`CODEX_ROUTER_NATIVE_TRANSPORT=websocket` (default `http`), pooled per credential with automatic fallback.
